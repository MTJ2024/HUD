## [1.0.0] - 2025-01-29

### Initial Release 🎉

#### Added
- Complete HUD system for FiveM ESX Legacy servers
- Configurable features with true/false settings in config.lua
- Vehicle speedometers:
  - Car/Motorcycle speedometer with KMH/MPH support
  - Boat speedometer for watercraft
  - Aircraft speedometer for planes and helicopters
- Player status bars:
  - Health indicator with critical health warning
  - Armor display
  - Hunger bar (ESX Status integration)
  - Thirst bar (ESX Status integration)
  - Stamina indicator
- Vehicle information display:
  - Fuel level gauge with low fuel warning
  - Engine health indicator with damage warning
  - Automatic vehicle type detection
- Location and time features:
  - Custom styled minimap with rounded corners
  - Current street name display
  - Zone/area name display
  - Time display with 12/24 hour format support
- GreenZone420 branding:
  - Custom server logo with marijuana theme
  - Green color scheme throughout HUD
  - Professional gradient effects and animations
- Extra features:
  - Cinematic mode (F9 key to toggle HUD)
  - Auto-hide when pause menu is open
  - Smooth animations and transitions
  - Performance optimized update intervals
  - High speed visual effects
  - Critical status warnings

#### Technical Features
- ESX Legacy compatible
- Minimal resource usage
- NUI-based interface with HTML/CSS/JS
- Responsive design
- Customizable theme colors
- Clean code structure with comments

#### Documentation
- Comprehensive README with features and setup
- Detailed installation guide
- Configuration documentation
- MIT License included
- Professional presentation
