DU BEKOMMST DIESE FEHLERMELDUNG?
→ Der Ordnername ist FALSCH!


❌ FALSCH:
──────────────────────────────────────────────────────────────────────────
resources/[HUD]/                    ← MIT Klammern = FEHLER!
resources/[greenzone420_hud]/       ← MIT Klammern = FEHLER!

server.cfg: ensure [HUD]            ← FALSCH!


✅ RICHTIG:
──────────────────────────────────────────────────────────────────────────
resources/greenzone420_hud/         ← OHNE Klammern = RICHTIG!

server.cfg: ensure greenzone420_hud ← RICHTIG!


INSTALLATION SCHRITT FÜR SCHRITT:
═══════════════════════════════════════════════════════════════════════════

1. DOWNLOAD
   - Dieses Repository als ZIP herunterladen
   - ODER: git clone https://github.com/MTJ2024/HUD.git

2. ORDNER RICHTIG BENENNEN
   - Extrahiere den Ordner
   - Benenne ihn um zu: greenzone420_hud
   - KEINE KLAMMERN [ ] verwenden!

3. IN DEN SERVER KOPIEREN
   - Kopiere greenzone420_hud nach: /resources/greenzone420_hud/
   
4. SERVER.CFG BEARBEITEN
   Füge hinzu:
   ensure greenzone420_hud

5. SERVER STARTEN
   - Keine Warnungen mehr!


WARUM KEINE KLAMMERN?
═══════════════════════════════════════════════════════════════════════════

FiveM Ordner-Regeln:

[ordner]  = KATEGORIE-ORDNER (mehrere Resources)
           Beispiel: [esx], [standalone]
           
ordner    = EINZELNE RESOURCE (eine Resource)
           Beispiel: greenzone420_hud, esx_menu


WENN DU IMMER NOCH FEHLER HAST:
═══════════════════════════════════════════════════════════════════════════

1. Prüfe den Ordnernamen:
   - Keine [ und ] Klammern
   - Nur greenzone420_hud

2. Prüfe die Ordnerstruktur:
   greenzone420_hud/
   ├── fxmanifest.lua  ← MUSS hier sein!
   ├── config.lua
   ├── client/
   │   └── main.lua
   └── html/
       ├── index.html
       ├── style.css
       └── script.js

3. Prüfe server.cfg:
   ensure greenzone420_hud  ← OHNE Klammern!
