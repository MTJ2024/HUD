WARUM?
═══════════════════════════════════════════════════════════════════════════

FiveM Ordner-Regeln:
- [ordner] = Kategorie-Ordner (mehrere Resources)
- ordner   = Einzelne Resource

Wenn man [HUD] benutzt:
1. FiveM denkt, es ist eine Kategorie
2. Findet aber fxmanifest.lua → Warnung!
3. Scannt client/ und html/ als separate Resources
4. Findet keine Manifeste dort → Warnungen!

LÖSUNG:
═══════════════════════════════════════════════════════════════════════════

1. Server stoppen
2. Ordner umbenennen: [HUD] → greenzone420_hud
3. server.cfg ändern: ensure greenzone420_hud
4. Server starten
