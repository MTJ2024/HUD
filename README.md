# GreenZone420 HUD

Ein professionelles HUD-System für ESX Legacy Server.

## Installation

1. Lade das Repository herunter
2. Benenne den Ordner zu `greenzone420_hud` (KEINE Klammern!)
3. Kopiere in `resources/greenzone420_hud/`
4. Füge in `server.cfg` hinzu: `ensure greenzone420_hud`
5. Konfiguriere in `config.lua`
6. Starte den Server neu

## Features

- Gesundheit, Panzerung, Hunger, Durst, Ausdauer
- Fahrzeug-Tachometer (Auto, Boot, Flugzeug)
- Minimap-Anpassung
- Standort und Zeit
- Vollständig konfigurierbar

## Konfiguration

Siehe `config.lua` für alle Einstellungen.
